Module: tests/setup

Préparation des tests : base MongoDB dédiée, isolée des vraies données.

  • Si MONGODB_URI_TEST est défini (en production, sur Render), les tests utilisent cette base de test, distincte de la base de l'application.
  • Sinon (en local), une base MongoDB en mémoire est démarrée.

Chargé par Mocha avant les fichiers de test (voir .mocharc.json).
