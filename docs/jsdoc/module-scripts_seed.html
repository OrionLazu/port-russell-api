Module: scripts/seed

Alimente la base MongoDB avec les données fournies (data/catways.json et data/reservations.json) et crée le compte de la capitainerie.

Usage : npm run seed Les collections catways et reservations sont vidées puis rechargées. Le compte administrateur est créé s'il n'existe pas encore.
