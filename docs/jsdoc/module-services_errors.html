Module: services/errors

Erreurs métier levées par les services.

Les services ne connaissent ni l'objet req, ni l'objet res, ni les codes d'état HTTP : ils lèvent une ServiceError portant un type métier, que le middleware de gestion d'erreurs traduit ensuite en réponse HTTP.
